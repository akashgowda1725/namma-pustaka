# Namma-Pustaka 📚
Smart Library Assistant for Rural Schools

## 📌 Overview
Namma-Pustaka is an Android application developed to digitize rural school libraries.  
Many village schools manage books manually, making it difficult to track issued books, overdue returns, and available resources.

This app transforms a simple school bookshelf into a smart digital library system using QR code technology and AI-assisted features.

---

## 🚀 Features

### 📖 Book Catalog
- Browse books by categories
  - Story
  - Science
  - History
  - Education
- Search books by:
  - Book Name
  - Author Name

### 📱 QR Code Borrow System
- Scan QR code on books
- Issue books to students digitally
- Easy check-in/check-out workflow

### ⭐ Review Corner
- Students can:
  - Give star ratings
  - Add short reviews

### 🏆 Reading Leaderboard
- Tracks:
  - Most active readers
  - Pages/books read monthly

### 🔔 Overdue Alerts
- Highlights overdue books automatically
- Changes overdue status color to red

### ➕ Add New Books
- Add books using camera-based entry
- Store book details digitally

## 🎯 Problem Statement

In many rural schools, libraries are managed manually without proper tracking systems.  
Students often do not know which books are available, and teachers struggle to manage issued books.

This results in:
- Lost books
- Poor resource management
- Reduced reading culture

Namma-Pustaka solves this problem by creating a simple and smart digital library system.
